CASE 08 / VusionGroup · Internship

Making technical support repeatable.

Combined L1 technical troubleshooting with structured case documentation and a searchable knowledge-base initiative.

Technical support / knowledge base
My roleTechnical Solutions Intern
PeriodAug — Oct 2025
DisciplinesEmbedded · Automation

The challenge

Make resolved electronic shelf-label support cases easier to document, search and reuse across the support team.

My contribution

  • Provided L1 technical support for electronic shelf-label systems, investigating access-point, connectivity, display and configuration issues.
  • Developed a structured case-mapping format with symptoms, diagnostic questions, resolution steps, keywords and validation evidence.
  • Created an Excel case database linked to detailed documentation to help colleagues locate related issues and solutions.
  • Documented a staged improvement proposal covering case capture, searchable knowledge organization and future AI-assisted retrieval.

A staged knowledge workflow

Capture the procedure in a consistent document, index the case in Excel, then explore how a future assistant could retrieve the relevant procedure with links to source evidence. The final AI-assisted stage was a proposal.

Outcome & scope

Created case-documentation examples, an Excel database and an implementation roadmap. No deployed AI assistant, measured reduction in resolution time or organization-wide adoption is claimed.
